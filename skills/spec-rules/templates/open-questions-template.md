# Open Questions

Only questions this cycle answers. A question whose answer comes later lives in
[Deferred questions](../future/deferred-questions.md).

Every question says what it delays. There is no second list of delayed work and no
count of questions, because a second list always drifts from the first one.

A solved question is deleted whole, not ticked. The answer lives in the decision note.

Questions carry no numbers. Link a question by its own words, so deleting one question
breaks no reference to another.

## The question, written as a question

What is already decided, and which data already exists. Link the entities, scenarios,
and ADRs that the question touches.

**Question.** The one thing nobody knows yet. Name who can answer it: a measurement,
a choice, or a person.

**Decides.** In a layered vault, the layer that owns the answer. A question to
another layer is how you ask for a change there.

**Delays.** What waits for the answer. Write `Nothing` when nothing waits, and name
what stands in place of the answer.
